Empieza aquí

  1. Seleccione el modo de cálculo:
    ⚬ CIDR para calcular una subredes tradicionales
    ⚬ VLSM para un direccionamiento con diferentes tamaños de subred.

  2. Ingrese una dirección IP válida: Utilice el formato decimal, por ejemplo 192.168.1.0.

  3. Defina la máscara de red: Especifica la máscara en notación CIDR, como /24.

  4. Indica la cantidad de subredes: Ingresa el número de subredes que deseas generar y visualizar en la tabla de resultados.

    5. VLSM
  5. Agrega subredes: Ingrese el nombre de cada subred junto con el número de hosts requeridos.

  6. Haga clic en “Calcular”: Se obtendran los resultados, que incluyen: dirección de red, IP inicial y final, la dirección de broadcast, el rango de hosts disponibles y mascara de subred.
