## 🚀 Características

**Modos de cálculo disponibles:**

### CIDR

- Permite calcular divisiones **uniformes** de una red base.
- Genera subredes con la misma máscara.
- Útil cuando todas las subredes requieren el mismo número de hosts. 

### VLSM (Variable Length Subnet Mask)

- Permite dividir la red en subredes con **máscaras de diferente longitud** según la cantidad de hosts requeridos.
- Optimiza el uso de direcciones reduciendo desperdicio. 

**Resultados que se muestran:**

- Dirección de Red
- Rango de IPs utilizables
- Dirección de Broadcast
- Máscara de subred (decimal y CIDR)
- Tabla con subredes generadas
